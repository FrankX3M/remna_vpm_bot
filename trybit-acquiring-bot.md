# Эквайринг Trybit в VPN-боте (vpnbot): реализовано

Статус: код встроен в бот (архив `vpnbot-trybit.zip`, патч `vpnbot-trybit.patch`). Тесты проходят на SQLite и на PostgreSQL 16 с настоящими миграциями: `test_trybit_core.py` (18 проверок подписи и логики), `test_trybit.py` (9 сценариев на БД), старые `smoke_test.py`, `test_web.py`, `test_bot.py`, `test_egress.py`. Не проверено: реальный Trybit, реальный Telegram, Caddy на VPS RU. Все ключи тестовые.

Документация Trybit: https://docs.trybit.com/ru (API v2, база `https://api.trybit.com/v2`).

## 1. Что такое Trybit

Криптоэквайринг: USDT (TRC20/TON/BEP20...), TON, BTC, ETH, LTC, SOL и др. Карт и СБП нет. Счёт создаётся в рублях, Trybit пересчитывает в крипту сам. Тарифы бота в `plan_prices` с валютой `RUB` (целые рубли).

Описание проекта (213 символов, без «картой/СБП»):

> Telegram-бот VPN Duck: продажа подписок на VPN-сервис для защищённого интернет-соединения. Клиент выбирает тариф, оплачивает криптовалютой в боте и сразу получает персональную ссылку-подписку для подключения.

## 2. Форма «Интеграция» в Trybit

| Поле | Значение |
|---|---|
| Способ интеграции | API |
| URL успешной оплаты | `https://t.me/<BOT_USERNAME>` (без `?start=`: Trybit дописывает `?order_id=...&invoice_uuid=...`, и параметр start ломается) |
| URL неудачной оплаты | `https://t.me/<BOT_USERNAME>` |
| URL для уведомлений | `https://sub.1rtp.ru/pay/trybit/postback` |

Формат постбэка в проекте Trybit: JSON. Подписка выдаётся постбэком/сверкой, а не переходом по ссылке.

Поток: пользователь выбирает тариф и способ «Криптовалюта (Trybit)» → создаётся заказ и счёт (повторный клик переиспользует тот же счёт) → кнопка со ссылкой на страницу Trybit → POSTBACK → `process_payment(provider="trybit", external_id=<INV-...>)`, то есть те же рефералы, скидки, события и `/regrant`, что и у Stars.

## 3.1. Выбор способа оплаты и монеты

«Купить» → **способ оплаты** → тариф → (для крипты) **монета/сеть**. В списке способов только те, что включены в «Настройки → Оплата» и у которых есть цена хотя бы у одного активного тарифа; если способ один, шаг пропускается. Банковские карты появятся сами, когда будет написан провайдер (`PaymentProvider`, регистрация в `main.py`) и заданы цены в его валюте: пока их нет, кнопки нет.

Монеты берутся из `TRYBIT_CURRENCIES`, порядок от дешёвой сети к дорогой: USDT·TON, TON, USDT·Solana, USDT·BEP20, LTC, USDT·TRC20, BTC, ETH, USDT·ERC20. Выбранная монета уходит в Trybit как `add_fields.cryptocurrency`, хранится в заказе (`coin`), счёт переиспользуется только для той же монеты. Пустой `TRYBIT_CURRENCIES` = подвыбора нет, монету выбирает клиент на странице Trybit. Рекомендуется `TRYBIT_CURRENCIES=USDT_TON,TON`.

Почему TON первым: сетевая комиссия платит клиент (`side_commission: client`). На тестовом счёте за 150 ₽ (≈1,76 USDT) в TRC20 она ≈1,4 USDT, в TON ≈0,2 USDT. Режим «комиссию платит мерчант» включать нельзя, пока в кабинете нельзя отключить TRC20 (у USDT TRC20/ERC20/USDC ERC20/USDT BSC в кабинете замочки): на малых тарифах это уводит в минус. В тестовом режиме API всегда отвечает USDT_TRC20, реальное поведение `cryptocurrency` видно только на первом боевом платеже.

## 4. Безопасность

* Постбэк без валидного JWT (HS256, SECRET KEY, обязательный `exp`) получает 401. В примерах Trybit токен необязателен, здесь это закрыто.
* Статус и сумма перезапрашиваются у API Trybit. Телу постбэка не верим.
* Счёт привязан к заказу (`invoice_uuid`), сумма и валюта сверяются, повторы безвредны (атомарный захват `pending → paid` + уникальность `payments(provider, external_id)`).
* `paid`/`overpaid` выдают подписку, `partial` только уведомляет админа и пользователя, `canceled` закрывает заказ и пишет пользователю.
* Панель недоступна в момент оплаты: платёж остаётся `granted=False`, админ получает подсказку `/regrant`.
* Тестовые счета игнорируются, пока `TRYBIT_ALLOW_TEST=false`.
* Ответ 500 при сбое обработки (а не 200), чтобы повтор или сверка довыдали подписку.

## 5. Публичный адрес постбэка

Бот и панель дома, наружу ничего не открыто. Путь запроса:

```
Trybit -> https://sub.1rtp.ru/pay/trybit/postback (Caddy на VPS RU)
       -> туннель AWG -> 10.66.0.2:443 (Caddy панели, сайт bot.1rtp.ru) -> vpnbot:8088 /trybit/postback
```

Фрагмент для Caddy на VPS RU лежит в `deploy/ru-caddy-trybit.snippet` (метод только POST, тело до 64 КБ, `Host: bot.1rtp.ru`). Не проверено на реальном сервере. Проверить: ACL RU → дом:443 (есть для Subscription Page), имя `bot.1rtp.ru` в сертификате панели, часы сервера синхронизированы (JWT живёт 5 минут), `WEB_ENABLED=true`. Админ-сайт остаётся доступным только из туннеля: наружу пробрасывается один путь.

## 6. Запуск

1. Распаковать `vpnbot-trybit.zip` вместо старого кода, вписать ключи в `/opt/vpnbot/.env`, выполнить `./07-bot-home.sh` (миграция применится сама).
2. Цены: `/setprice ID СУММА RUB`. Способ оплаты появится у пользователей рядом со Stars.
3. Добавить фрагмент в Caddy на VPS RU, перезагрузить Caddy, проверить curl-командой из комментария в сниппете (ответ 401 Invalid token означает, что цепочка работает).
4. Тестовый режим Trybit: `TRYBIT_ALLOW_TEST=true`, купить тариф через бота, в кабинете «Платежи → Тестовые» нажать «Подтвердить счёт без оплаты», проверить выдачу подписки и ответ 200 в «Истории постбэков».
5. Подать заявку на проверку (до 24 часов). После одобрения `TRYBIT_ALLOW_TEST=false`. Изменение раздела «Интеграция и API» потом возможно только через тестовый режим и повторную проверку (приём реальных платежей приостанавливается).

## 7. Открытые вопросы (проверить в тестовом режиме)

1. Единицы `amount`: в документации «сумма в USD», но есть параметр `currency`. Бот после создания счёта сверяет `amount_in_fiat` и `fiat_currency` с запросом и откажет с понятной ошибкой («Не удалось создать счёт»), если они не совпадут. Тогда суммы нужно будет пересчитывать в USD.
2. Состав JWT-payload и повторные отправки постбэка в документации не описаны: не используем payload, добавили сверку раз в минуту.
3. Минимальная сумма счёта и список доступных монет для вашего проекта: смотреть в кабинете.
4. Мониторинг: число заказов `pending` старше 2 часов и ответы 500 на `/trybit/postback`.
